# YouTube Planner

動画案・台本・アナリティクス・メモを管理する静的Webアプリ(index.html 1ファイルのみ)。

## GitHub Pagesで公開する手順
1. GitHubで新しいリポジトリを作成(例: `youtube-planner`)
2. `index.html` と `README.md` をリポジトリ直下にアップロード
3. Settings > Pages > Source を `Deploy from a branch`、Branch を `main` / `(root)` にして Save
4. 数分後、`https://<ユーザー名>.github.io/youtube-planner/` で開けます

## 機能
- アナリティクス: 登録者数・総再生回数・月間投稿本数(目標あり)・次の動画までの日数をカード表示。動画のリンクから再生回数・いいね・題名・長さ・投稿日・コメント数・タグ・公開時刻(日本時間)・サムネイルを取得して一覧に表示し、投稿間隔も表示。ページを開いたとき・アナリティクスタブに切り替えたとき・ブラウザのタブに戻ったときに、自動で最新データを取得します(30秒以内の再取得は省略)。投稿日の新しい順で表示し、列ごとのフィルター・並び替えが可能
- 動画作成案: 台本(話者・内容・挿絵・効果・コピー)、構成・概要、案ごとのToDo、CSV書き出し(ゆっくりムービーメーカー4 Lite用)。並び替え、投稿予定日までの残り日数表示、Ctrl+Z / Ctrl+Y で元に戻す・やり直す
- 設定: APIキー、チャンネルID、登録者目標数・月間投稿目標数(登録者数はAPI取得のため編集不可)、動画種別、話者の追加・編集・削除

## 追加機能
- 作業時間の計測: 動画作成案の編集画面にストップウォッチ(作業開始 → 作業中断 ⇄ 作業再開)。ページを閉じても計測は続き、案ごとに累計されます。「対象動画」にアナリティクスの動画を選ぶと、アナリティクスに「作業時間」「1分あたり作業時間(作業時間 ÷ 動画の長さ)」の列と平均カードが表示されます
- 並び替えはすべてドラッグ(左端の点 ⋮ をつかんで移動)。動画作成案の一覧は「手動」モードで有効
- データ保存: localStorage と IndexedDB に二重保存、10分ごとに最大30件の履歴、設定タブからJSON書き出し・読み込み・履歴からの復元

## API設定
Google Cloud Consoleで「YouTube Data API v3」を有効化してAPIキーを発行し、設定タブに入力します。
キーはコードに書かず、画面から入力してください(ブラウザ内にのみ保存されます)。

## データ保存
入力内容はブラウザのlocalStorageとIndexedDBに保存されます(端末間の同期はありません)。ブラウザの設定や容量整理で消えることがあるため、大事な更新のあとは設定タブの「データをJSONで書き出す」で保管してください。
